# Crisp Farm Voice Studio 🌾

A local-first, offline-capable agricultural workshop and voice field logger built for farmers, agricultural workers, and growers. Part of the **Crisp Suite / HandleVault** ecosystem.

## ✨ Features

- **Voice & Text Field Logger:** Dictate field observations hands-free using Web Speech API integration or type notes directly.
- **Farm Chores & Schedule:** Manage daily farming tasks, irrigation schedules, and chores with persistent local storage.
- **Offline Crop & Pest Guide:** Built-in quick references for staple crops (Rice, Corn, Tomato, Eggplant) and management tips.
- **Night/Day Shift Themes:** Ergonomic high-contrast themes optimized for bright outdoor daylight or late-night planning.
- **100% Offline & Private:** Runs entirely client-side in your browser with zero login walls or external server tracking.
- **Single-File Architecture:** Lightweight, fast, and easy to deploy or modify.

---

## 🚀 Quick Start / Usage

1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. (Optional) Deploy instantly via GitHub Pages using the included GitHub Actions workflow.

---

## 📂 Repository Structure

- `index.html` — The core single-file application (UI, Web Speech API logic, and styling).
- `repo.js` — Shared Crisp Suite repository metadata helper.
- `manifest.json` — Progressive Web App (PWA) manifest configuration.
- `.github/workflows/deploy.yml` — Automated GitHub Pages deployment pipeline.
